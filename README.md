## التشغيل المحلي

يتطلب Node.js 22 أو أحدث. لا يحتاج الموقع مكتبة واجهات أو حزمة بناء.

```sh
npm ci --ignore-scripts
npm run dev
```

يشغّل الأمر خادماً محلياً على المنفذ 4173 للأصول ودوال `/api/ai` و`/api/session`. هذا محوّل تطوير، وليس محاكاة Netlify الكاملة. دون أسرار Netlify، تعمل الأدوات المحلية ويعيد AI حالة عدم التهيئة المتوقعة. لا تضف أسرار الإنتاج إلى البيئة السحابية أو Git.

## ما يحتويه المشروع

- `public/index.html`: الصفحة الأصلية المطورة؛ CSS/JS منفصلان في `public/assets`، خط عربي محلي، وواجهة RTL مع وضع إنجليزي، ومساعد مدار اختياري بلا مشاركة تلقائية للسجلات.
- `public/assets/experience.mjs`: الرئيسية الجديدة ولوحة اليوم والتنقل بين الأدوات من بيانات المستخدم الفعلية.
- `public/assets/core.mjs`: حسابات سعرات وماكروز حتمية للبالغين؛ لا يعتمد الحساب على AI.
- `public/assets/nutrition.mjs`: مكتبة من 500 وجبة (250 لخفض الوزن و250 لزيادته)، بمقادير وبيانات مكونات موثقة المصدر، وخطط محسوبة محلياً. زر التغيير في الاقتراحات السريعة والمخطط يستعرض البدائل المناسبة قبل تكرارها ويحافظ على الاستبعادات. تظهر مكتبة موحّدة بدلاً من قسم الـ60 وصفة القديم، ويستخدم دفتر الأكل نفس بيانات الـ500 وجبة.
- `public/assets/training.mjs`: برنامجا 4 و 5 أيام من الصفحات المرئية للكتاب، تسجيل المجموعات وRIR والراحة، ولوحة تقدم محلية.
- `netlify/functions`: AI، جلسات دعوة موقعة، وحدود طلبات Redis مشتركة. لا يُستورد مفتاح أو دالة ZIP القديمة.
- `docs/source/protocoltraining-original.pdf`: الكتاب المرفوع دون تعديل.
- `docs/book`: مصدر الطبعة المحسنة القابل للصيانة؛ راجع [مراجعة PDF](docs/pdf-review.md) والملف الناتج في `docs/artifacts`.
- `public/sw.js`: تخزين أصول عامة للعمل دون اتصال بعد تحميلها؛ طلبات AI والجلسات لا تُخزن في CacheStorage.

بيانات الغذاء والوزن والتدريب والمفضلة محفوظة في المتصفح. يمكن تصديرها أو حذف بيانات مدار بتأكيد صريح. لا توجد مزامنة سحابية أو حسابات شخصية. تبدأ الطلبات المتصلة عند الضغط على إرسال، دون مربع موافقة منفصل. إرفاق هدفك في المساعد اختياري، ولا تُرسل السجلات بمجرد فتح الموقع.

## إعداد Netlify قبل AI

مجلد النشر `public` والدوال `netlify/functions`. راجع [الأمان ومتطلبات Netlify](docs/security.md) و[مسودة الخصوصية](docs/PRIVACY.md). القيم المطلوبة داخل Netlify Functions فقط:

- `GROQ_API_KEY`: مفتاح جديد بعد إلغاء المكشوف.
- `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN` لحدود طلبات ذرية مشتركة.
- `RATE_LIMIT_SALT` و`AI_SESSION_SECRET`: قيم سرية عشوائية قوية، 32 محرفاً على الأقل لكل منهما.
- `AI_PUBLIC_ACCESS=true`: يبدأ جلسة عامة تلقائياً عند إرسال السؤال؛ `AI_ACCESS_CODE` مطلوب فقط للوضع الخاص.

غياب أي شرط حماية يمنع استدعاء المزود. لا يعتبر نجاح اختبارات البدائل إثباتاً لعمل Groq أو Redis أو نشر Netlify الفعلي. **يلزم المالك إلغاء مفتاح Groq القديم؛ لم يُثبت تدويره.**
