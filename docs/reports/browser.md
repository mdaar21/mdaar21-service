# تقرير اختبار الواجهة — 20 أكتوبر 2026

نجحت **25 من 25 حالة** على الشفرة النهائية في مجموعتي تشغيل: 16 حالة للعرض والميزات الأصلية والأمان والخصوصية، و9 حالات للتغذية والتدريب والعمل دون اتصال والمساعد. شُغّل Chromium 154.0.8037.57 وPlaywright مع خادم التطوير المحلي. استجابات AI والجلسة بدائل اختبار؛ لا مفاتيح حقيقية أو طلبات Groq. النتائج التفصيلية في مساري `/workspace/mdaar-local/browser-final-core/results.json` و`/workspace/mdaar-local/browser-final-features/results.json` في البيئة الحالية.

## إعادة التشغيل

```sh
npm run dev
# في طرفية ثانية، مع Playwright وChromium مثبتين:
npm run test:browser
```

البيئة الحالية توفر Playwright. في بيئة أخرى ثبّته محلياً للتطوير دون تغيير اعتماديات الإنتاج، وحدد `CHROMIUM_PATH` عند اختلاف موقع المتصفح. يمكن تخصيص العنوان بواسطة `MDAAR_TEST_URL` ومسار النتائج بواسطة `MDAAR_TEST_ARTIFACTS`.

يقسم `MDAAR_TEST_GROUPS` التشغيل عند الحاجة: `layout,legacy,privacy,security,nutrition,training,pwa,assistant`. الوضع الافتراضي يشغلها جميعاً. يولّد الاختبار `results.json` ولقطات للأقسام الثمانية، ويعيد حالة خروج غير صفرية عند الفشل.

## المراجعة البصرية والحدود

رُوجعت لقطات الأقسام الثمانية على الجوال. كشف الاختبار تجاوز عرض قائمة تمارين التقدم؛ أُصلح وأعيد الاختبار. كشفت المراجعة البصرية عناصر إدخال غير منسقة في مكتبة الوصفات والمخطط، وأُصلحت لتستخدم التصميم العام. أُعيد تشغيل جميع الحالات الـ25 في المجموعتين بعد هذه الإصلاحات، ورُوجعت اللقطات النهائية للقوائم الثماني؛ تظهر جميع أزرار التنقل على الجوال في صفين.

اللقطات وJSON التفصيلي تُولَّد في `/workspace/mdaar-local/browser` افتراضياً، ولا تحتوي على بيانات مستخدم حقيقية. هذه محاكاة أحجام عرض؛ لا تثبت اختبار أجهزة فعلية أو Safari/Firefox أو قارئ شاشة. لم تختبر جلسة Netlify المنشورة، أو Groq/Redis الفعليين، أو قبول التثبيت على أنظمة التشغيل. نجاح جمع المغذيات لا يعادل مراجعة وصفة بواسطة مختص.
