# بروتوكول التحول — المصدر القابل للصيانة

هذه **طبعة مراجعة تحريرية مصوّرة** من 34 صفحة. تستند إلى المحتوى المرئي للكتاب الأصلي وإلى الأسماء والجداول نفسها في `public/data/training-programs.json`. لا تمثل اعتماداً من مختص تدريب أو تغذية. النسخة الأصلية محفوظة دون تعديل في `docs/source/protocoltraining-original.pdf`.

الملفات:

- `index.html`: مصدر القراءة والتصدير، يدعم العربية وRTL ويتكيف مع شاشة الجوال.
- `book.css`: التصميم، الخطوط، جداول الطباعة، وترقيم الصفحات.
- `identity/`: الأغلفة الأصلية محفوظة كرسوم SVG متجهية، مع خريطة الصفحات والبصمات. تحافظ على الشعار والرسوم التشريحية والخطوط والأقواس الأصلية دون تحرير الصورة.
- `fonts/`: خطوط Noto Sans Arabic مع ترخيصها. لا يُحمّل الكتاب خطوطاً من الإنترنت.
- `site-qr.svg`: QR مولّد لعنوان الصفحة 3 الأصلية: `https://shimmering-mousse-7e10fd.netlify.app`. وجود الرابط لا يعني نشر هذا الإصدار. تعذر فحص الوجهة عبر سياسة شبكة البيئة؛ يجب فحصها قبل توزيع الكتاب.
- `../../scripts/build-book.py`: النص التحريري وقوالب الصفحات وتوليد HTML/PDF.
- `../artifacts/protocoltraining-review.pdf`: ملف PDF للمراجعة، مع عناوين وروابط وفهرس داخلي قابل للنقر.
- `../artifacts/mdaar-protocol-original-identity-v2.pdf`: نسخة مطابقة بترقيم اسم جديد، لتجنب فتح النسخة القديمة المخزنة مؤقتاً.

## إعادة البناء

من جذر المستودع، باستخدام Python 3 وChromium النظام، وPlaywright وpypdf المثبتين بالإصدارات المحددة:

```sh
python3 -m pip install -r scripts/requirements-book.txt
python3 scripts/build-book.py
```

لا يحتاج التطبيق نفسه إلى هذه الحزم. يستخدم التصدير Playwright مع Chromium الموجود، دون تنزيل متصفح أو تغيير إعدادات الحماية. يبدأ خادم HTTP مؤقتاً على عنوان loopback ومنفذ متاح، ويغلقه بعد التصدير. السياسة السحابية تمنع `file://`؛ لذلك لا تستخدمه كطريقة بديلة.

لبناء HTML فقط دون أدوات PDF:

```sh
python3 scripts/build-book.py --html-only
```

عدّل النصوص داخل سكربت البناء، والتصميم في CSS، والتمارين في بيانات التدريب المشتركة، ثم أعد التوليد. أغلفة الهوية الأصلية (1،7،8،10،14،16،21،22،24،27،29) مستوردة بصرياً من PDF كـSVG لمعاينة HTML، وتُرسم في PDF النهائي مباشرةً بمؤثرات PDF المتجهية الأصلية دون تغيير شكلها؛ تحرير تكوينها يتطلب تحرير الأصل المتجهي أو استبداله مع مراجعة البصمة، وليست نصوصها عناصر HTML قابلة لإعادة الصف. يوفر HTML عنواناً ومحتوى بديلين وروابط تنقل أصلية لكل غلاف. لا تعدّل HTML المولّد وحده لأن البناء يستبدله. يتحقق المصدّر من 34 قسماً ومن بصمات أصول الهوية والبطاقات، ومن عدم خروج المحتوى أو تداخله مع التذييل في صفحات المحتوى قبل كتابة PDF. أغلفة SVG مقيدة بإطار A4 وتُفحص بصرياً؛ لا تطبق عليها معادلة تذييل النص العادي. افحص PDF بصرياً بعد أي تعديل، خصوصاً الصفحتين 20 و34 والسجلات.

## نطاق الطبعة

حُفظت تقسيمة الأيام والقوائم والبدائل المرئية، وحُررت إرشادات السلامة والخصوصية والتقديرات، وصححت إحالات الصفحات. تتضمن الطبعة بطاقات التمارين المرئية المستخرجة من الملف المرفوع دون تغيير الصورة. توجد خريطة الأسماء والصفحات والبصمات في `figures/manifest.json`، ويستخدم التطبيق الصور نفسها. تحسين الصور النقطية وشرح الأداء بالفيديو والمراجعة المهنية للتقنية والحجم الأسبوعي ما زالت أعمالاً مستقلة قبل الاعتماد النهائي. لم ننسب ترخيصاً جديداً لصور المصدر. لا تستعمل الجداول وحدها لتعلم حركة جديدة.

المصدر يحتوي طبقات نصية مخفية قديمة لا توافق الصور المرئية؛ لذلك لا يُعاد استخراج قوائم التمارين آلياً من النص وحده. راجع `docs/pdf-review.md` قبل تحرير البرنامج.

## استعادة الهوية البصرية

استجابة لمراجعة المالك، عادت بدايات برنامجي4و5أيام والدفع والسحب والعلوي والسفلي إلى تكوين الأغلفة الأصلي الكامل، بدلاً من صفحات شرح عادية. صفحات المحتوى والجداول سوداء وذهبية بإطار هادئ، وتبقى سجلات الكتابة عاجية لتسهيل الطباعة. لا تُحمّل الأغلفة خطوطاً أو صوراً خارجية.

يمنع التصدير النهائي خطوط حواف أقنعة SVG التي قد تظهر من Chromium حول بعض العناوين، برسم مؤثرات صفحة الغلاف الأصلية داخل PDF كـForm XObject بعد التصدير. لا يُعدل الأصل ولا تُرسم الأغلفة نقطياً. تبقى روابط ومحتويات القراءة البديلة وبنية Tagged المولدة محفوظة.
