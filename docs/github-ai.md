# خدمة مدار لرابط GitHub

الموقع يبقى على GitHub Pages. خدمة Cloudflare Worker في هذا المستودع تنفّذ طلبات Groq؛ لا تُنشر أي أسرار مع الموقع. لا يلزم إنشاء جلسة يدوياً أو تفعيل مربع موافقة. يُرسل السؤال عند الضغط على إرسال، وإرفاق الهدف اختياري.

## التفعيل من المتصفح

1. افتح https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Fnbbttdhnybnnb-crypto%2FMdaar21%2Ftree%2Fcloudflare-worker وأنشئ حساب Cloudflare إن لم يكن لديك. اختر الخطة المجانية دون ترقية مدفوعة، واربط مستودع GitHub عند طلب ذلك. المصدر فرع `cloudflare-worker`، ومجلد الجذر `/`، وإعداد Wrangler موجود في الجذر؛ أمر النشر `npx wrangler@4.152.0 deploy`، دون أمر بناء إضافي.
2. عيّن `GROQ_API_KEY` كـ Secret داخل Cloudflare فقط. يعلنه ملف Wrangler سراً مطلوباً؛ إذا لم تطلبه واجهة النشر، أضفه من Worker → Settings → Variables and Secrets ثم أعد النشر. عدم وجوده يعيد 503 ويمنع الاتصال بالمزود. لا تضع المفتاح في GitHub Pages أو ملف wrangler أو المحادثة. لا تُعد استخدام مفتاح سبق كشفه.
3. احتفظ بقيمة `ALLOWED_ORIGIN=https://nbbttdhnybnnb-crypto.github.io`. تنشئ الهجرة كائن SQLite لحفظ حدود الاستخدام ومفتاح التوقيع الداخلي؛ لا يحتاج مالك الموقع مفاتيح Redis أو مفاتيح توقيع إضافية. إذا كانت الخطة المعروضة لا تشمل Durable Objects، توقف قبل اختيار أي ترقية مدفوعة.
4. بعد اكتمال النشر، انسخ رابط Worker العام الذي ينتهي بـ `workers.dev`. هذا الرابط ليس سراً. يلزم إدخاله عند بناء نسخة Pages بالأمر أدناه ونشر الناتج إلى فرع `gh-pages`. رفع كود الخدمة إلى GitHub وحده لا ينشئ حساب Cloudflare أو ينشر Worker.

## ربط نسخة Pages

استخدم رابط الخدمة الحقيقي، بلا مسار أو معاملات:

```sh
python3 scripts/build-github-pages.py --output /tmp/mdaar-pages-connected --service-origin https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev
```

الناتج يضبط أصل الخدمة وCSP والروابط وملف الخصوصية. انشر محتوى الناتج فقط إلى جذر `gh-pages`؛ أبقِ المفاتيح والدوال خارج فرع الموقع. لا تنشر رابط الاختبار الوهمي المستخدم في الفحوص. دون `--service-origin` تظل الخدمات معلنة غير متاحة ولا يُرسل طلب إلى خادم خارجي.

## التحقق قبل إعلان التشغيل

- نفّذ `npm test` و`npm run check`. `npm run test:worker-browser` يستعمل نسخة Pages محلية مبنية على أصل الاختبار `https://mdaar21-service.test.workers.dev` واستجابات خدمة محكومة؛ ليس اختبار مزود حقيقي.
- بعد تشغيل Worker، افحص CORS من أصل GitHub الفعلي، ثم سؤالاً عاماً غير شخصي عبر الموقع، وإعادة السؤال دون موافقة أو دعوة. تحقق من شكل JSON والعربية ورسائل الخطأ.
- افحص انتهاء الجلسة وإغلاق المساعد وحصص الاستخدام في بيئة تجريبية دون رفع حدود الإنتاج. لا تعرض رموز الجلسة أو أجسام ردود خطأ المزود في التقارير.

## حدود الحماية

يسمح CORS بأصل GitHub المحدد فقط. الجلسة موقعة ومقيدة بالأصل ومعرّف الاتصال لمدة 15 دقيقة؛ يحتفظ المتصفح بالرمز في الذاكرة، لا localStorage أو ملفات ارتباط عبر المواقع. ترفض الخدمة غياب جلسة سليمة، وتحسب Durable Objects حصصاً ذرية: 25 طلباً لكل معرف اتصال يومياً و400 إجمالاً و5 في الدقيقة. لإنشاء الجلسة حد مستقل 20/يوم للمعرف و200 إجمالاً و5 في الدقيقة. حذف العدادات المنتهية يتم بمنبّه التخزين؛ لا تُحفظ نصوص الأسئلة في العداد. تغيير الشبكة أو اليوم قد يجدد الجلسة تلقائياً. الفشل في الحماية يمنع طلب المزود.

لا يحوّل فحص Origin الخدمة إلى هوية مستخدم؛ يمكن للبرامج تزويره، وتظل الحصة العامة دفاع تكلفة أساسي. للموقع العام ذي الزيارات الكبيرة، راجع الحصص وحماية إساءة الاستخدام في الحساب قبل التوسع. لا تضع رمز GitHub أو Cloudflare في الواجهة لتجاوز الحاجة إلى تفعيل الحساب.

ملف الخصوصية الناتج عند الربط يوضح المعالجة بواسطة Cloudflare وGroq والجلسة في الذاكرة. لا تُرسل السجلات بمجرد فتح الموقع. إلغاء الطلب من المتصفح لا يسترجع بيانات وصلت للمزود.
